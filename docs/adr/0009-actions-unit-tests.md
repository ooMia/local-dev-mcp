# ADR 0009: Actions는 단위 테스트만 실행

- 상태: Accepted
- 결정일: 2026-11-06
- 범위: GitHub Actions의 검사 범위와 로컬 검증의 구분

사용자는 Actions에서 외부 바이너리 의존 테스트를 전부 제외하거나 단위 테스트만 실행하는 방식 중 선택하도록 했다.
기존 `unit` marker를 기준으로 단위 테스트만 실행한다. 형식·린트·타입 검사는 유지한다.
바이너리 사용 여부를 별도 분류로 추적하는 대신 이미 정의한 테스트 계층을 재사용한다.

Actions에서는 통합·설치·실제 Git snapshot 릴리스·배포물 검사를 실행하지 않는다.
로컬의 전체 품질 검사와 hooks·평가 불변성·릴리스 검사는 유지하며, CI 성공으로 이를 대체하지 않는다.
실패 테스트를 성공이나 자동 skip으로 바꾸지 않고 실행 범위 자체를 명시한다.
이 결정은 PR 출처·squash·평가 정책이나 원격 강제 부재에 대한 기존 결정을 변경하지 않는다.
현재 실행 명령과 증거의 범위는 [검사 안내](../testing.md#actions와-로컬-검증의-범위)가 소유한다.
