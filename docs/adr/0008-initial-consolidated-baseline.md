# ADR 0008: 정리한 초기 기준선의 일회성 게시

- 상태: Accepted
- 결정일: 2026-11-06
- 범위: 이 저장소의 최초 정리 기준선과 잘못된 평가 메타데이터의 일회성 보완
- 부분 대체: [ADR 0006](0006-native-pr-workflow-mvp.md)의 PR 출처 요구와 [ADR 0005](0005-assessed-squash-and-batched-releases.md)의 기존 평가 불변성을 아래 초기 기준선에만 한정하여 대체한다. 이후 통합·릴리스 정책은 유지한다.

## 결정과 이유

사용자는 누적 개발을 PR로 재현하는 비용을 줄이고 로컬 기능 단위 커밋을 우선 보존하기로 했다.
정리된 네 커밋과 게시 전 검수 수정 커밋 하나를 최초 main 기준선으로 직접 게시하도록 준비한다.
실제 게시와 원격 설정 변경은 검증된 정확한 후보 SHA 및 관측한 원격 SHA를 제시한 뒤 별도로 승인받는다.
실재하지 않는 PR 출처를 만들지 않는다. PR 하나로 squash하면 기능별 결과가 합쳐지고, 네 PR을 순차
재구성하면 이번 초기 정리의 비용 절감 목적을 잃으므로 초기 기준선에만 예외를 둔다.

기능 경계 커밋은 `0366f552e22e7f8dcdc610912e3d382845fbe7d8`,
`3a5c7ddd3c2fbbd4bdfd845d212aa2944815d45a`, `31595d4c3c3795e9f079874b96a0fcb58fd730ff`,
`3d95fc600c9d4d6b1a28256399ae65e8687022d5`다. 검수 수정은 이 이력을 재작성하지 않고 그 위에 기록한다.
최초 원격 비교 지점은 `2ae0de2d520725b17355d0f2fca90dd64240a11d`이며, 실제 게시 전에도 동일한지 재관측한다.
다르면 새 변경을 검토하며 강제 push로 덮어쓰지 않는다. 일반 bootstrap 자동 우회 기능은 추가하지 않는다.

원본 개발 브랜치는 원격에 게시하지 않는다. 원본 refs·미커밋 파일·구간 대응은 로컬 복구 자료에 보존한다.
`Source-Base`·`Source-Head`·`Source-Tree`는 그 로컬 원본의 출처이며, 원격에서 해당 원본 SHA를 fetch할 수
있다는 보장이 아니다. 원격 이용자는 게시한 기준선 커밋과 그 tree를 정본으로 사용한다.

## 잘못된 평가의 한정 보완

기존 `.changes/isolated-pr-worktrees.toml`에는 필수 `contract`와 `assessed_by`가 없어 snapshot 파싱 자체가
실패한다. `supersedes`를 추가해도 정정 관계 계산 전에 실패하므로 일반 정정 경로로 복구할 수 없다.
사용자 승인에 따라 원본 bytes와 hash를 로컬 복구 자료에 보존하고, 이 파일에 한해 위 두 필드를 추가한다.
`impact`·`summary`·`reason`·`migration`의 기존 판단은 그대로 유지하며 `assessed_by = "agent"`는 이번
보완 판단의 주체를 나타낸다. 최초 기준선 이후에는 기존 평가의 수정·삭제를 허용하지 않는다.

## 적용 경계

기존 로컬 main은 정리 후보와 계보가 갈라져 있으므로 정상 fast-forward 승인으로 옮기지 않는다.
별도의 깨끗한 복제본에서 정리된 이력만 main 후보로 준비한다. 원본 저장소의 main이나 설치된 hooks를
끄거나 수정하지 않는다. 첫 기준선은 일반 main 통합으로 처리하지 않으며, 게시 후 그 main에서 hooks를
설치·진단한 뒤 후속 개발을 시작한다. 버전 변경·태그·패키지 발행은 이 결정에 포함하지 않는다.

이후에는 게시된 main에서 기능 브랜치를 만들고 평가·검사·실제 PR 출처를 갖춘 squash를 사용한다.
이 저장소는 비공개를 유지하고 현재 계정 조건의 원격 보호 강제 부재를 수용한다. 로컬 검사·PR 통합 절차는
유지하되 서버가 직접 push나 UI 병합을 막는다고 주장하지 않는다. 계정·공개 범위 변경은
별도 결정이며 이 예외를 일반 보호 우회로 확장하지 않는다.
구체적 절차와 한계는 [초기 기준선 게시](../tools/workflow/initial-baseline.md)가 소유한다.
