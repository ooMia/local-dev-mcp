# README

## Prepare

```sh
source .venv/bin/activate
```

## Development

```sh
uv build # cmd + shift + B

uv format # alt + shift + F

uv run pytest # (cmd + ;) + A

uv version # major, minor, patch, stable, alpha, beta, rc, post, dev
```

## Execution

```sh
uv run local-dev-mcp # ctrl + F5
```
